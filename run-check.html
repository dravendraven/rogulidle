Tripwires

A tripwire fires or it does not, and when it fires there is a defect to find. None of these is a quantity to push — the firing condition is printed next to each value, and every number comes from real runs of the real bot. Keep this tab visible while it runs, or the browser throttles it.

Two instruments, and their numbers are not interchangeable. Same engine, same bot — one plays with the shop and one without, so a depth from the first is not a depth from the second.

1 · the naked run — the shop switched off

Independent runs, empty hands every time. This is the baseline (test/baseline.md) and a lower bound on a session — not a description of one, because only the first run of a real session is ever naked.

2 · the chain — a session, with the shop in it

Runs in a row, each starting with what the shop bought after the last one — win or lose. Dying does not end a chain; dying is the reset inside it. One chain is one sample, not one per run, so raise the chains rather than the length for a steadier read.

The six shared wires are the same bars as above, read on a different game — that difference is the comparison. The last two exist only here: independent runs have no session to break.
